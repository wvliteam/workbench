# 仓库路由与检索协议

## 进入源码前

1. 从 workspace 的仓库清单或项目说明确认目标仓库。
2. 优先阅读仓库画像和仓库自身的协作说明。
3. 只有源码 checkout 能证明产品实现；workspace 配置只能证明工作台如何配置。

## 检索

- 仓库入口可能是软链。检索工具不跟随软链时，使用真实绝对路径或 `grep -R`、`find -L`、`rg -L`。
- 连续两次无结果不能直接判定目标不存在；先用已知存在的符号验证检索链路，再更换检索方式。
- 跨仓库影响、变更顺序和集成观察点由主编排者统一判断。

## 边界

- 未挂载或只有画像的仓库不能凭画像猜实现，也不要自行 clone。
- 仓库清单、源码路由和权限范围以当前 workspace 的配置为准，不在通用 workbench 文档中固化项目名称。
