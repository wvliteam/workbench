# Workspace 通用参考

| 文档 | 主要内容 | 适用问题 |
| --- | --- | --- |
| `../../AGENTS.md` | 工作台阶段、权限、契约和多端约定 | 判断流程边界与主线程职责 |
| `../output-contract.md` | 输出信封、证据和禁止事项 | 组织角色回报 |
| `../repo-routing.md` | 仓库路由、软链检索和源码证据 | 定位实际源码 |
| `../toolchain.md` | 工具链选择和验证判据 | 运行构建、测试和门禁 |

本目录只放跨 workspace 可复用的操作协议；具体项目的仓库清单、路径和版本矩阵由项目 workspace 自己补充。
